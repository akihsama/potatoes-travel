# 土豆旅行 · Potato Travel（游戏本体）

横版像素风网页小游戏。永夜大陆，光即货币、武器与希望。

## 运行方式

**方式一（最简单）**：直接双击 `index.html` 用现代浏览器打开（Chrome / Edge / Firefox）。

**方式二（本地服务器，推荐）**：

```bash
cd game
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 操作

| 按键             | 功能                           |
| -------------- | ---------------------------- |
| ← → / A D      | 移动                           |
| 空格 / W / ↑     | 跳跃（松键可截断跳高）                  |
| J / Shift      | **冲刺**（无敌帧，撞死影鼠；壳状态下撞伤石蕈傀）   |
| ↓ / S + 方向（地面） | **滚动**（缩成球，加速通过低矮处）          |
| ↓ / S（空中）      | **压扁**（快速下坠，落地震死附近影鼠）        |
| L（长按）          | **发光**（扩大光照半径，驱散雾蛾，消耗体力）     |
| E              | 交互（床/喷泉炼金台/宝箱/路牌；喷泉可恢复 1 点心） |
| R              | 驯化附近的野生影鼠（需背包有影鼠饵，最多 3 只）    |
| 1 - 5          | 使用物品槽                        |
| Tab / I        | 旅行日记                         |
| B              | 永夜图鉴                         |
| Q / Esc        | 关闭面板                         |

**触屏**：手机浏览器打开即自动显示虚拟按键（摇杆 + 跳/冲/光/E + 物品槽 + 日记/图鉴；靠近野生影鼠时额外出现 **R 驯化键**），**请横屏游玩**；桌面端可用 `?touch=1` 强制开启触屏层调试。对白/结局点屏幕即可推进。

## 系统一览

- **五能力**：滚动 / 弹跳（药水）/ 冲刺 / 压扁 / 发光——对应土豆蛋设定集
- **采集**：7 种资源，其中月见草（夜）、露水（05-08 清晨）、星屑（00-04 深夜）为**时间窗资源**；每种采集物在所在场景的生成区域内**随机落点**，采完后一段时间在原地点附近换新位置重生
- **炼金**：5 配方，需先在各地图找到 3 个炼金部件（炉芯→炼金草地、冷凝器→草原、透镜→密林）解锁；炼金草地中央的**喷泉**即炼金台，周围堆满炼金瓶，互动还可恢复 1 点心（该处不生怪，只有材料）
- **昼夜**：白昼 24 分钟 : 夜晚 9 分钟（击败 Boss 后夜晚缩至 4 分钟）；木屋的床可一觉睡到清晨并回满体力
- **光照**：入夜后屏幕被黑暗笼罩，只有土豆蛋的光与其光源能照亮；光是货币也是武器
- **敌人**：影鼠（压扁/冲刺）、雾蛾（畏光，微光弹驱散）、石蕈傀（硬化壳冲撞）
- **Boss**：不可名状之物——无形体，分三层护壳；日光瓶照形后冲刺撞击，一次照形内连中 3 次触发**瘫痪 10s（攻击力 +30%）**。**打法见下方「Boss 战详解」**
- **驯化影鼠**：炼金合成「影鼠饵」（苔藓×2+星屑×1），炼金草地全场景无敌对生物——带上饵料去**院子/草原/密林**靠近野生影鼠按 **R** 驯化（最多 3 只）；永久追随，Boss 战每次 -2 HP
- **场景移动**：院子里的木屋通过**点击木屋木门**进入（也可走近按 E）；竞技场等场景间沿用边缘传送
- **收集**：日记残页 ×6、图鉴 ×4
- **存档**：localStorage 自动存档（每 20 秒 + 睡眠/传送/Boss 战后）

### Boss 战详解：不可名状之物

Boss 没有可见形体，分**三层护壳**（每层 45 HP，共 135）。靠一套状态切换循环；照形窗口耗尽会隐去，需再用日光瓶。

**攻击方式（状态机）**

|        | 行为                                     | 玩家对策                                 |
| ------ | -------------------------------------- | ------------------------------------ |
| 休眠（隐形） | 完全隐身，缓慢向最近玩家漂移；**非冲刺态接触扣 1 心**         | 保持移动，别原地站                            |
| 照形（静靶） | 日光瓶照形后显形并**静止**，窗口 15 / 12 / 8 秒（随层递减） | 冲刺撞击造成伤害（每次 -10）；**一次照形内连中 3 次触发瘫痪** |
| 瘫痪     | 连中 3 次后定身 10 秒（紫色电光）                   | 黄金输出期：冲刺伤害 ×1.3（每次 -13），影鼠也疯狂撕咬      |
| 蓄力（前摇） | 约 0.55s 前摇 + 怒吼 + 身体发亮                 | 立刻冲刺（无敌帧）或横向闪开                       |
| 冲撞     | 直线高速冲撞约 0.7s；非冲刺态被撞扣 1 心               | 预判弹道走位，或冲刺无敌穿过                       |

**通关循环（每层）**

1. 日光瓶照形 → Boss 静止 → 冲刺撞击（每次 -10）
2. 连中 3 次 → **瘫痪 10s，攻击力 +30%**（冲刺每次 -13）
3. 瘫痪期 + 影鼠协同（每次 -2）迅速削掉该层剩余 HP
4. 一层 HP 归零 → Boss 换形态进入下一层；三层全清 → 永夜破晓

**驯化影鼠（强力协同）**

- 在炼金草地中央的**喷泉**炼金台合成「**影鼠饵**」（苔藓×2 + 星屑×1，需先拿到炼金炉芯）
- 靠近野生影鼠按 **R** 驯化（**最多 3 只**，屏幕提示 x/3 进度）→ 永久追随你（跨场景），Boss 战自动撕咬，每次 -2 HP
- 影鼠只在 Boss 非休眠时进攻——带它贴近 Boss 正下方即可

**关键提示**

- 每层 45 HP > 3 次基础撞击（30），**稳定连中 3 次必触发瘫痪**——别一下下乱撞，瞄准了连续冲
- 进竞技场先开宝箱拿 1 个日光瓶；日光瓶（月光花×3+露水×2+星屑×2，需透镜部件）与影鼠饵都要在外面积攒，**场内无法合成**
- 冲刺（J / 右 Shift）带**无敌帧**——既是输出手段也是躲冲撞的核心

## 场景动线

```
木屋（床·日记1） ⇄ 院子（日记2） ⇄ 炼金草地（喷泉炼金台·炉芯·日记3）
       ⇄ 草原（日记4·冷凝器） ⇄ 密林（浓雾·日记5·透镜） ⇄ 竞技场（Boss·日记6·日光瓶宝箱）
```

## 技术

单页 Canvas + 原生 JS（经典脚本加载，无构建、无依赖），逻辑分辨率 1536×1024（3:2），CSS 自适应缩放。素材为 48 张透明底像素 PNG（见 `assets/`）。
